Картинки и описания объектов из Steam, Discogs или FantLab

Steam — для игр: ищется игра с таким же названием, как у объекта (без учёта регистра, знаков ™ ® © и пунктуации), картинка — шапка страницы игры, описание — краткое описание игры (по-русски, если есть). Discogs — для музыки: название объекта должно быть в виде «Группа - Альбом», ищется альбом с тем же названием у той же группы, картинка — обложка, описание — примечания альбома (Notes); объекты без « - » в названии пропускаются. FantLab — для книг: название объекта «Автор - Книга» (как у дисков; без « - » ищется просто по названию), картинка — обложка, описание — аннотация (FantLab — база фантастики, книги других жанров там есть не всегда). Сервисы ограничивают число запросов: на объект уходит около 1,5 секунды для Steam (около 3 секунд вместе с описанием) около 2 секунд для Discogs (до 4 секунд вместе с описанием) и около 3 секунд для FantLab. Страницу можно закрыть: импорт продолжится, прогресс будет виден здесь.
