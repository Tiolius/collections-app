# Коллекции (Java)

Простое веб-приложение для хранения коллекций и объектов.
У коллекции: название, тип, картинка. У объекта: название и поля, которые задаёт тип коллекции.
Типы коллекций и их поля настраиваются на странице «Настройки» (ссылка в шапке).
Поля выбираются из набора: платформа, формат, статус прохождения, цена.
Там же для типа можно задать цвет строки объекта в зависимости от статуса (например, пройденные — зелёным).
Изначально есть типы «Игры (диски)», «Игры (цифровые)», «Книги», «Музыка (диски)».
Вход по имени и паролю; любой может зарегистрироваться (ссылка на странице входа).
У каждого пользователя свои коллекции, объекты и типы коллекций. Пароль меняется в «Настройках».
Java 21 + Spring Boot + Thymeleaf + SQLite. Всё, включая картинки, хранится в одном файле `data/app.db`.

**Адрес приложения: http://localhost:47321** (порт 47321)

## Требования
Только Docker с Docker Compose. Java и Maven на компьютере не нужны: сборка идёт внутри Docker.
Первый запуск занимает несколько минут (скачиваются зависимости), следующие — быстрее.

## Запуск
- Linux / macOS: `./start.sh`
- Windows: `start.bat`

Приложение запускается на порту **47321** — откройте http://localhost:47321

## Остановка
- Linux / macOS: `./stop.sh`
- Windows: `stop.bat`

Данные сохраняются в папке `data` между перезапусками.
Резервная копия — просто скопируйте `data/app.db`.

## Структура
```
src/main/java/app/
  App.java            точка входа
  WebController.java  все страницы и действия
  Repo.java           работа с базой (SQL)
  Entry.java          коллекция или объект
src/main/resources/
  application.properties  настройки (порт, база, лимит картинки)
  schema.sql              таблицы
  templates/              HTML-страницы (Thymeleaf)
```

## Разработка без Docker
```
DATA_DIR=./data mvn spring-boot:run
```
В этом режиме приложение будет на http://localhost:8000 (внутренний порт приложения).

## Порт
Снаружи приложение доступно на порту **47321**; внутри контейнера оно слушает порт 8000.
Чтобы сменить внешний порт, поменяйте первое число в `docker-compose.yml` (`"47321:8000"`)
и адрес в `start.sh` / `start.bat`.

## Переход на версию с пользователями (один раз)
Если база создана до появления пользователей, её нужно перенести: все данные станут данными
пользователя **Evered** с пустым паролем (пароль затем можно задать в «Настройках»).
Windows (PowerShell, в папке проекта):
```
.\stop.bat
Copy-Item data\app.db data\app-before-users.db
docker run --rm -v "${PWD}\data:/data" -v "${PWD}\tools:/tools" alpine sh -c "apk add -q sqlite && sqlite3 /data/app.db '.read /tools/migrate-to-users.sql'"
.\start.bat
```
Повторный запуск скрипта ничего не меняет (он останавливается на первой ошибке).
